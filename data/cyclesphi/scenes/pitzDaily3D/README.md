# pitzDaily3D 62M (XiFoam LES flame): CyclesPhi scenes of the v2 animations

These are the final scenes of the v2/v3 animations (2026-10-26). The files here are the
v2 last frame (time index 195600, i.e. the end of the camera orbit) of each shot. The final
animations are v3: the same shaders and orbit, 300 frames, an export every 50 steps
(`VER=v3 FIRST=193050 STEP=50 NF=300 make_v2_scenes.sh`), outputs in
`$S/renders/pitzDaily3D/v3/pitz_v3_*.mp4`. Every
`.xml` needs its `.xml.bin` next to it; the `.bin` holds the colour ramps of the vortex shader.

| File | Shot | Grids loaded |
|---|---|---|
| `pitz_v2_flame_195600.xml` | blackbody flame front | `b`, `T` |
| `pitz_v2_vortex_195600.xml` | Q-criterion vortex tubes coloured by \|U\| | `Q`, `U_mag` |
| `pitz_v2_combined_195600.xml` | flame + vortices (two closures added) | `b`, `T`, `Q`, `U_mag` |

All per-frame XMLs are generated by `scripts/vis/v2/make_v2_scenes.sh`, which calls
`scripts/vis/v2/make_pitz_scene.py`. The XMLs are written to
`$S/renders/pitzDaily3D/v2/<shot>/scene/`. Only the camera matrix and the VDB path change
from frame to frame.

The data is one VDB per frame from mesioVDB:
`$S/runs/pitzDaily3D/62M/VDB_v2/pitz_<timeindex>.vdb`. Each file has 4 float grids
(b, T, Q, U_mag), 1536 x 266 x 199 voxels (h = 0.19 mm), and covers the box
x -0.004..0.29, y +-0.0254, z +-0.01905 m.

Render with `scripts/vis/v2/render_xml.sh filmic_mhc 1920x1080 64 <out_dir> <xml...>`.
That command uses the OCIO config `data/cyclesphi/colormanagement/config_filmic_mhc.ocio`
(the "AgX" view hard-coded in the cycles PNG writer is remapped to Filmic sRGB + the look
"Medium High Contrast").

## Common scene parts

- **Object transform**: the VDB box is centred at 0 and scaled so that its diagonal is 10
  scene units. Densities and emission strengths are therefore given per scene unit
  (1 unit = 30 mm). The data axes are kept: x is streamwise, y is up, z is spanwise.
- **Camera**: an eased orbit (`0.5 - 0.5 cos(pi t)`) over the 260 frames. It starts as a wide
  3/4 view (azimuth 100 deg, elevation 22 deg, distance 0.30 m) and ends as a close 3/4 view
  (azimuth 135 deg, elevation 33 deg, distance 0.245 m). The target is about (0.15, -0.004, 0) m
  and the vertical fov is 30 deg. Azimuth is measured in the x-z plane, with 0 = +x.
- **World**: the light rays see a dim bluish ambient (0.05, 0.055, 0.07). The camera rays see a
  vertical gradient (`texture_coordinate.generated -> separate_xyz.y -> map_range ->
  mix_color`), from (0.002, 0.002, 0.004) at the bottom to (0.018, 0.022, 0.035) at the top.
  This gives a dark navy background that is not pure black.
- **Film**: exposure 2.83 (+1.5 stops), Blackman-Harris filter 1.5 px.
- **Integrator**: biased volume ray marching with `volume_max_steps 1024` (the default step
  size is the voxel size), `max_volume_bounce 0` (direct light only), and the
  OpenImageDenoise denoiser on the CPU (`use_denoise`, prefilter `accurate`, quality `high`).
  Use 64 spp: in the tests, 16, 64 and 128 spp + OIDN looked the same, and the noise between
  two seeds is 0.8/255 at 64 spp (0.6/255 at 256 spp).

## Flame shader (blackbody, Blender-fire style)

The flame front is the b = 0.5 sheet (b is the regress variable: 1 unburnt, 0 burnt).

```
b  --> math(1 - b) --+
b  ------------------+--> math multiply --> math x4 = w1 = 4 b (1-b) in [0,1]
w1 --> math power(25) = wpow                (crisp sheet: half width at b = 0.43/0.57)
T  --> map_range(250..288 -> 0..1) = maskT  (inactive voxels have T = 0: hides box faces/solid)
w  = wpow * maskT
wpow --> map_range(0..1 -> 1000..3000 K) --> blackbody --> emission_color
w * 40  --> emission_strength   } principled_volume #1 (front)
w * 1.0 --> density             }   colour (scattering albedo) = black -> pure absorption
T  --> map_range(1000..1700 K -> 0..1) = g    (hot products)
blackbody(1300 K) --> emission_color          } principled_volume #2 (products glow)
g * 0.15 --> emission_strength, g * 0.3 --> density
add_closure(#1, #2) --> output.volume
```

Notes:
- The power shaping (instead of a broad window) is what makes the sheets crisp. With
  power 3 the front is a blurry, over-exposed slab (tests B1-B4 in `$S/renders/pitzDaily3D/v2/tests/grade_B.png`).
- The visual temperature comes from the shaped weight. The centre of the sheet is the hottest
  (yellow) and its edges are cooler (orange/red). The faint products glow gives a dull red
  underside and depth.
- The black absorption of the sheet darkens what lies behind it, which gives depth cues
  without any scattering.

## Vortex shader (Q tubes, key + rim light)

```
Q     --> map_range(3e5 .. 1.2e7) --> rgb_ramp alpha (0 below t=0.02, 0.25 @ 0.25, 0.75 @ 0.6, 1 @ 1) = a
U_mag --> map_range(2 .. 28 m/s) --> rgb_ramp colour: deep blue -> blue -> cyan -> ice white = c
principled_volume: color = c (scattering albedo), anisotropy 0.3,
                   density = a * 400, emission_color = c, emission_strength = a * 5
```

Lights (sun lamps; the +Z axis of the light object is the travel direction):
- key light, strength 5, travelling (-0.3, -1, -0.5): from above, on the camera side;
- rim light, strength 25, colour (0.75, 0.88, 1.0), travelling (-0.45, -0.25, 0.85): from behind
  the tubes towards the camera, which gives bright silhouettes.

## Combined shot

The combined shot uses the same flame graph and the vortex graph with density 200,
emission 25, key light 3 and rim light 15. The two volume closures are added with
`add_closure`. The flame stays the dominant element, and the cool tubes show through the
sheets (test CC3).

Contact sheets are in `$S/renders/pitzDaily3D/v2/tests/`:

animations (960x540, 60 frames) are `tests/preview_<shot>.mp4`. The temporal flicker metric
(`scripts/vis/v2/flicker.py`, second temporal difference over bright pixels, 8-bit units):

|---|---|---|
| flame | 0.73 | 0.35 |
| vortex | 1.91 | 2.32 |
| combined | 1.25 | 1.19 |

The vortex shot is dominated by the fast change of the Q field.
